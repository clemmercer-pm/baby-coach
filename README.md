# Baby Coach

A simple, stage-aware roadmap for expecting and new parents. Enter your due date and it shows **what to focus on this week** — things to *do*, things to *watch for*, and things *worth noting* — plus what's **coming up next**, so nothing catches you off guard.

Built as a first vibe-coded, deployed project — plain HTML, CSS and JavaScript, no build step.

## Run it
Open `index.html` in any browser. That's it — no install.

## How it works
- `index.html` — the page.
- `styles.css` — the look.
- `data.js` — the roadmap content (one entry per stage).
- `app.js` — works out which stage you're at from your due date and shows it.

Your due date is stored only in your own browser (localStorage). Nothing is sent anywhere.
